# Cooper Gurrie

Static landing page for https://coopergurrie.com.

The existing Vercel project is coopergurrie-landing in Cooper Gurrie Projects.

Serve this folder as the site root. No build command or dependencies are needed.
Font licenses are bundled under assets/fonts/.

Development verification and audit resolutions are in [docs/portfolio-review.md](docs/portfolio-review.md).
Browser regressions use Playwright via `requirements-dev.txt`; the published page still has no runtime dependencies.
